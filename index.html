01 / 02 AI workspace

AETHER

Adaptive AI Workspace

A voice-first AI workspace where six studios — study, interviews, code, research, files, and tasks — share one persistent memory and one conversation.

  • Six studios in one workspace: Study, Interview, Code, Research, Files, and Tasks, each with its own tools and context.
  • Speak or type: browser speech recognition, plus Deepgram and ElevenLabs, with responses streamed token-by-token over SSE.
  • FastAPI and Next.js on async PostgreSQL — with cited research, user-controlled memory, auth, and a Docker setup.
  • FastAPI

02 / 02 Game · Web

Smooth Snake

A classic, rebuilt twice

Snake with smooth, interpolated movement — shipped twice: a Pygame desktop game and a Flask browser build deployed on Render.

  • Interpolated motion so the snake glides between cells instead of jumping, at any frame rate.
  • Two builds from one idea: a Python/Pygame desktop game and a browser version served by Flask.
  • Arrows or WASD, space to pause, R to restart — the same controls in both versions.
